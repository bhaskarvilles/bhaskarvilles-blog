FRONT MATTER FIELD GUIDE:
==========================

title:
- Include primary keyword naturally
- Keep under 60 characters
- Make it compelling and clickable
- Use title case

slug:
- Use hyphens, not underscores
- Include primary keyword
- Keep it short and descriptive
- All lowercase
- No special characters

date:
- Original publication date
- Format: YYYY-MM-DD

lastmod:
- Last modification date
- Update when making significant changes
- Signals freshness to search engines

categories:
- 2-4 categories maximum
- Use existing categories when possible
- Capitalize each word
- Broad topics

description:
- 150-160 characters (Google's display limit)
- Include primary keyword in first 120 characters
- Write for humans, not just search engines
- Make it compelling - this is your ad copy
- Include a benefit or value proposition
- End with a period

tags:
- 5-10 tags per post
- Mix of:
  * Primary keyword
  * Secondary keywords
  * Long-tail keywords
  * Related topics
- Use lowercase with hyphens
- Be specific and relevant

author:
- Full name for authority
- Consistent across all posts

image:
- Featured image for social sharing
- Recommended size: 1200x630px
- Optimize file size (< 200KB)
- Use descriptive filename
- Store in /static/images/posts/

CONTENT OPTIMIZATION CHECKLIST:
================================

□ Primary keyword in:
  - Title
  - First paragraph (within first 100 words)
  - At least one H2 heading
  - Meta description
  - URL slug
  - Image alt text

□ Heading hierarchy:
  - Title = H1 (automatic)
  - Main sections = H2
  - Subsections = H3
  - Never skip levels

□ Internal links:
  - 3-5 contextual internal links
  - Link to related posts
  - Link to category/tag pages
  - Use descriptive anchor text (not "click here")

□ Images:
  - Add descriptive alt text to ALL images
  - Include keywords naturally in alt text
  - Optimize file sizes
  - Use WebP format when possible

□ Content quality:
  - Minimum 1,000 words (1,500-2,500 for pillar content)
  - Answer user intent completely
  - Use short paragraphs (2-3 sentences)
  - Include bullet points and lists
  - Add examples and actionable tips

□ Readability:
  - Use simple language
  - Short sentences (< 20 words)
  - Active voice
  - Transition words
  - Scannable format

□ Call-to-action:
  - End with clear next steps
  - Encourage engagement
  - Link to related content

KEYWORD RESEARCH TIPS:
======================

1. Use tools:
   - Google Keyword Planner (free)
   - Ahrefs Keywords Explorer
   - SEMrush Keyword Magic Tool
   - AnswerThePublic
   - Google Search Console (existing data)

2. Target keywords with:
   - Decent search volume (100+ monthly searches)
   - Low to medium competition
   - High relevance to your content
   - Commercial or informational intent

3. Focus on:
   - Long-tail keywords (3-5 words)
   - Question-based keywords
   - "How to" keywords
   - Comparison keywords
   - Location-based keywords (if relevant)

4. Analyze competitors:
   - What keywords are they ranking for?
   - What's their content structure?
   - What's missing in their content?
   - How can you do better?

INTERNAL LINKING STRATEGY:
===========================

Link to:
1. Related blog posts (most important)
2. Pillar pages for main topics
3. Category/tag pages
4. Homepage (occasionally)
5. About/Contact pages (when relevant)

Anchor text best practices:
- Use descriptive text (not "click here")
- Include keywords naturally
- Make it contextual
- Keep it concise (2-5 words)
- Vary your anchor text

Example good anchor text:
✓ "Learn more about AI implementation"
✓ "Our guide to blockchain technology"
✓ "Full stack development best practices"

Example bad anchor text:
✗ "Click here"
✗ "Read more"
✗ "This article"
